Curlybrace is a free MongoDB GUI for Mac.

Browse, query, edit and compare your MongoDB collections in a native Mac app. No account, no trial, no paid tier, and the source is open.

Download for macOS View the source

Early release for Apple Silicon Macs. Licensed MIT or Apache-2.0.

What you can do with it

The basics, done carefully. Here is what works today, plus one feature arriving in the next release.

Connect the way your servers need
SCRAM, X.509 and LDAP sign-in, TLS, replica sets and mongodb+srv:// URIs. Reach private servers through an SSH tunnel via a bastion host, with the host key checked before anything is sent. Kerberos is included and still experimental.
Keep passwords out of files
Passwords and SSH secrets are stored in the macOS Keychain. The saved connection list never contains them, and they never appear in logs or error messages.
See documents three ways
Open a collection and switch between a tree, a table and raw JSON. Pages hold 50 documents, and long arrays are summarised so big documents stay readable.
Query without leaving the page
Type a filter, sort, projection, skip and limit as JSON and run it. If something is wrong, the app says what, and your previous results stay on screen.
Edit without losing types
Insert, edit, clone and delete documents. The editor uses canonical extended JSON, so numbers, decimals, dates, binary data and MinKey keep their exact BSON type. Any _id works: ObjectId, string, number, UUID or a compound value.
Compare collections or whole databases
Pick a source and a target, even on different servers, compare two collections or a whole database at once, and see what is only on one side and what differs. Match documents by _id or by your own key, ignore fields or array order, and open any difference to see the changed fields. It is read-only: nothing is written to either database. The key must be unique, and on large collections it needs an index. If the key is not unique, it shows which values repeat. New in the next release.
Built to not lose your data
Deletes ask for confirmation and show the document’s _id. A page shown with a projection is read-only for edit and clone, so a partial copy can never overwrite the full document. Unsaved editor text survives a stray click.

Install it in a minute

For Apple Silicon Macs. The app isn’t notarized by Apple yet, so macOS asks you to confirm the first launch.

  1. Download curlybrace-…-macos-arm64.zip from the latest release and unzip it.

  2. Move Curlybrace into your Applications folder.

  3. Right-click the app, choose Open, then Open again. Or clear the quarantine flag once from a terminal:

    xattr -dr com.apple.quarantine "/Applications/Curlybrace.app"
Go to the latest release

Come build it with us

The app is small and young, and that makes it a good place to leave a mark. The next features are open for anyone to take.

You do not need to be a Rust expert. Fixing a bug, writing a test or improving a doc is a real contribution. If you want to build a whole feature or bring the app to another platform, the contributing guide shows how the code is organised and how releases work.
